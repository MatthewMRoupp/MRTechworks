Minecraft's Next Updates Bring Winter Features—and a First Look at 2027

Published November 16, 2026 · Preview details checked November 16, 2026

Minecraft's next game drop is taking shape in public tests. Mojang's fourth 2026 drop previews include winter-inspired blocks and gameplay changes, while a separate announcement offers an early look at features planned for 2027. These are different releases: testing does not mean a feature has shipped to the standard game.

What's being tested for the fourth 2026 drop?

Recent Java snapshots and Bedrock previews show snow bricks, packed-ice and calcite building variants, along with cold-weather gameplay experiments. Java Snapshot 7 introduced a larger calcite block family and the “Flurry” music disc by Hyper Potions, which can appear in igloo basement chests. Later snapshot notes include bug fixes, not a new public release date.

Bedrock Preview 26.70.24, dated November 10, also describes testing for an Invisible Armor world setting, Joy-Con mouse controls on Nintendo Switch 2, and additional fixes. Preview features and settings can change before release, and individual features may vary between Java and Bedrock testing builds.

What's planned for 2027?

At TwitchCon, Mojang revealed a throwing disc and off-hand parity improvements for the first game drop of 2027. Those features are not part of the fourth 2026 drop. Mojang's announcement should not be read as a confirmed day-and-month launch schedule.

Should players install a preview?

Players who want a stable world should generally wait for the standard release. Betas, previews and snapshots are work-in-progress software. Back up worlds before experimenting, and avoid opening an irreplaceable world in a test build without a separate copy.
