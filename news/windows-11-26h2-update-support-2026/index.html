Windows 11 26H2: How to Check Your Version and Support Date

By MR Techworks · Published November 13, 2026

Original event: September 29, 2026 — Windows 11 26H2 general availability

Windows 11 has several supported releases, and a monthly update is not the same thing as a feature update. Understanding your version helps you avoid running an installation that no longer receives normal security servicing.

What 26H2 changes for the support timeline

Microsoft lists Windows 11 version 26H2 as available beginning September 29, 2026. Its published servicing dates currently extend through October 10, 2028 for Home and Pro and October 9, 2029 for Enterprise and Education. These dates describe a specific release, not the retirement of Windows 11 overall.

Version 25H2 remains a separate supported release. Microsoft's version 26H1 was designed for newer devices and is not presented as an in-place upgrade for existing computers running 24H2 or 25H2.

Find your version

Press Windows+R, type winver, and press Enter. The dialog reports the Windows release and OS build. You can also check Settings, System, About, under Windows specifications.

Compare the exact edition and version with Microsoft's Windows release-health table. A larger build number is not by itself a reason to force an upgrade.

Why devices do not all update together

Feature updates may be rolled out gradually, held for hardware compatibility, or managed through business policies. That is different from monthly cumulative security patches, which address supported releases.

If Windows Update does not offer a feature release, check known issues and compatibility information instead of overriding safeguards blindly. Before a major change, verify backups and encryption recovery keys.

What to do now

Record your Windows version, install applicable security updates, check manufacturer driver guidance and ensure the release remains in support. For company-managed equipment, coordinate changes with IT.

Microsoft updates its release-health information, so review the linked official chart when making a future upgrade decision.
