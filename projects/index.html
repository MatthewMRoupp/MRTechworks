Data Analytics

Data Analysis and Forensic Technology Job Simulation

Computer networking, data analysis, data modeling, data structures, data visualization tools, formal communication, log analysis, planning, programming, Python programming, software development, spreadsheet skills, and web security.

This project was completed as part of a business technology simulation focused on analyzing factory telemetry and compensation data for Daikibo Industrials. The goal was to use data tools to identify operational downtime patterns and support an internal investigation into pay equality across multiple factory locations.

For the telemetry portion, I worked with JSON data collected from four international factories. The data included machine status reports sent every ten minutes throughout May 2021. I imported the data into Tableau, created a calculated downtime measure, and built visual dashboards to determine which factory had the most machine downtime and which machine type contributed most to the issue.

For the equality portion, I worked with an Excel compensation table containing factory locations, job roles, and equality scores. I added a classification column that grouped each role into Fair, Unfair, or Highly Discriminative categories based on the equality score. This helped turn raw score data into clearer business insight.

This project strengthened my skills in data cleaning, calculated fields, dashboard filtering, Excel formulas, and turning technical results into useful business recommendations.

What I worked through

  • Imported and analyzed JSON telemetry data in Tableau to find factory machine downtime patterns.
  • Created calculated fields to turn "unhealthy" machine statuses into estimated downtime minutes.
  • Built dashboard filters so selecting one factory changed the machine breakdown chart automatically.
  • Used Excel formulas to classify equality scores into Fair, Unfair, and Highly Discriminative categories.

Networking

Home Network Segmentation and Wi-Fi Mesh Setup

Fiber network, switch topology, mesh placement, and device separation.

I planned a home setup that improved coverage while separating devices by purpose, making the network easier to manage and troubleshoot. This started as a growing project at a family member's property, where Wi-Fi needed to cover two neighboring houses while sharing one internet connection.

One thing I would change is running an Ethernet backhaul between the two houses. At the time, that would have required more work than they wanted to take on, so the connection between locations remained wireless.

The project also helped shape my plans for larger home networking setups involving managed switching, a home server, PoE security equipment, Wi-Fi access points, and wired Ethernet connections throughout the property.

What I worked through

  • Physical path from modem to router to switch to mesh
  • Network separation for personal, household, and guest use
  • Signal testing and connectivity checks across the space
  • Validation that devices stayed on the correct network

Open Demo

Payroll Calculator Notes

This demo is based on my C++ payroll coursework. The original idea started with basic input, calculations, and output for hours worked and hourly pay.

This web version expands the idea by adding overtime, filing status, estimated tax deductions, and a step-by-step math breakdown.

  • Regular pay is calculated from hours up to 40.
  • Overtime is calculated at 1.5 times the hourly rate.
  • Taxes are estimated using simplified demo logic.
  • Net pay is calculated after deductions and estimated taxes.

This is a class and portfolio demo, not an official payroll or tax tool.
